# craft：排版、间距、色彩、布局、动效、图片

数值来自 `tokens.mjs emit` 产出的 token。规则是"用 token 里的值"，不是"记住这些数字手敲"。

## 1. 排版

**字号阶梯**（`--text-*`，默认档）：

| token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12px | 元信息、表格脚注（不要更小） |
| `--text-sm` | 14px | 标签、次要说明 |
| `--text-base` | 16px | 正文下限 |
| `--text-lg` | 20px | 引言、卡片标题 |
| `--text-xl` | 26px | 区块标题 |
| `--text-2xl` | 34px | 次级大标题 |
| `--text-3xl` | `clamp(40px, 5vw, 64px)` | 页面主标题（次级页） |
| `--text-display` | `clamp(52px, 7vw, 104px)` | 首屏主张 |

- 行高：正文 1.5–1.65；大标题 1.0–1.15；不要全局一个行高。
- 字重：一个页面最多三档（如 400 / 500 / 700）；标题固定一档，别在同一层级混用。
- 行宽：`max-width: 66ch`（token `--measure`），永远别让正文横跨 1400px。
- 字距：大标题可以 `-0.02em`，最小不低于 `-0.04em`；**小写标签永远不要 `letter-spacing` + `uppercase` 组合**（Floor 13）。
- 字体族最多两个，第三个必须是"角色字体"（等宽只给数字/代码）。
- 中文正文配西文衬线要注意：衬线体只给标题和引文，正文用无衬线更稳。
- 禁止：`text-align: justify` 用于中文短行、斜体单词嵌在正体标题里、用字号当层级唯一手段。

## 2. 间距与栅格

- 基准 4px；所有间距落在 4/8/12/16/24/32/48/64/96（token `--space-*`）。
- 密度：compact 乘 0.8，normal 1，airy 1.25；由配方定，整页统一。
- 区块上下内边距统一为 `--space-section`（96px，随密度缩放）；不要每个区块自己定一个值。
- 容器：`max-width: var(--container)` 居中，左右 padding 24px；1920 以上让留白变宽，不要让内容变宽。
- 栅格：`grid-template-columns: repeat(auto-fit, minmax(0, 1fr))`；**含图轨道必须 `minmax(0, 1fr)`**，否则长标题会把列撑破。
- 相邻区块的间距大于区块内的间距，层级才清楚。
- 禁止：用卡片间距补齐留白、用 `margin-top` 负值叠元素、用绝对定位做常规布局。

## 3. 色彩

- 全部 oklch；纸（背景）、墨（正文）、muted（次要）、accent（一处强调）、border（线）五个语义 token 起步。
- 对比度：正文与 placeholder ≥4.5:1，大字号（≥24px 或 ≥19px 粗体）≥3:1。检查器不做对比度计算，**你算一遍**。
- 彩色底上的次要文字：从那个色相的墨色派生，不要用灰（灰压彩底是典型 AI 味）。
- 强调色只占画面极小面积（按钮、一个数字、一条线）；一个页面一个强调色。
- 暗色不是反色：纸用 L≈14–18%，墨用 L≈94% 且带一点纸的暖色相；纯 `#000`/`#fff` 是 Reflex。
- 状态色（成功/警告/危险）也要进 token，且与 accent 色相拉开 ≥60°。
- 禁止：紫蓝渐变、双主色、彩色阴影、低透明度色块叠色块。

## 4. 布局与首屏

- 首屏必须在 1280×800 内同时看到：主标题、一句说明、主操作。做不到就减内容，不是缩字号。
- 首屏只有两种姿态：**左对齐叙事**（文字左、视觉右）或**居中宣言**（大标题 + 一个物件）。不要"半边文字 + 三个图标"。
- 移动端：320px 起不横向滚动；触控目标 ≥44×44（含 `padding`）。
- 表格在窄屏改为纵向卡片列表，不要横向滚动主内容。
- 导航 ≤6 项 + 一个主操作；页脚是"桅杆式"（品牌 + 链接列 + 一行版权），不是第二个导航。
- 禁止：卡片网格当默认结构、每个区块都居中、`position: fixed` 的吸顶元素超过两个、用 `z-index: 9999`。

## 5. 动效

- 只动 `transform` / `opacity` / `filter` / `clip-path`；时长 150–250ms（配方可给更慢），曲线 `--ease-forge`。
- 一页最多一次入场动画，且内容在无脚本时可见（`@starting-style` 或先可见后动画）。
- 必须有 `prefers-reduced-motion: reduce` 兜底（Floor 5）。
- hover 位移 ≤2px；不要缩放超过 1.02。
- 交互反馈优先：按下、加载、成功失败，比滚动花活更有价值。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation: none !important; transition: none !important; }
}
```

## 6. 图片与图形

- 优先真实照片/真实产品截图；没有就留槽位（标注尺寸和内容），**不要画 SVG 插画糊弄**。
- 图片必须 `alt`（内容图写内容，装饰图写空）；`width`/`height` 或 `aspect-ratio` 必填，防抖动。
- 一张图只承担一个信息；不要图里塞文字。
- 图形语言统一：同一套描边粗细、同一套圆角；图标用一套图标库，**不用 emoji 当图标**。
- 背景纹理是预算项：只在该配方明确要求时使用，且不能降低文字对比度。

## 7. 文案

- 标题写成断言，不写"欢迎来到"。
- 按钮写动作和结果："开始导入" > "提交" > "确定"。
- 错误信息三段：哪里错 → 为什么 → 怎么改。
- 空态写"为什么空 + 下一步做什么"，不是"暂无数据"。
- 数字带单位和口径（"2 分钟"、"99.9%（过去 90 天）"）；没有来源的数字不要写。

## 8. 浏览器自带件（最便宜的可信度）

这些默认值不属于任何设计系统，必须一起设计：

```css
::selection { background: var(--accent); color: var(--paper); }
:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
a { text-underline-offset: 3px; text-decoration-thickness: 1px; }
td, th { font-variant-numeric: tabular-nums; }
html { scrollbar-color: var(--muted) transparent; caret-color: var(--accent); }
```

## 9. 反模式清单（见到就改）

- 每个区块都是"图标 + 标题 + 两行说明"的三连卡片。
- 首屏一个大数字 + 三个小统计。
- 结尾必有邮件订阅输入框。
- 渐变色文字、玻璃拟态装饰、彩色左边框提示条。
- 全站只有一个居中容器，所有内容都居中。
- 用 emoji 当图标、用 `01 / 02 / 03` 当装饰序号（除非顺序本身有信息）。
- 手写 `z-index: 9999`、`!important` 超过 3 处。
