FAIL 不可豁免

15 条，任何情况下都必须修。
#规则 id问题与改法
1 color/literal 颜色没走 token
把色值提进 :root / @theme 的 token 块，组件只引用 var(--x) 或语义类
2 tokens/missing 有颜色但没有 token 块
加 :root 或 @theme，把所有色值集中声明
3 motion/transition-all transition: all
只过渡真正变化的属性：color、background-color、transform、opacity
4 motion/layout-property 过渡布局属性
width/height/top/left 的过渡会掉帧，改用 transform
5 motion/no-reduced-motion 有动画但没有 reduced-motion 兜底
加 @media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation: none !important; transition: none !important } }
6 layout/overflow-x-hidden overflow-x: hidden
用 overflow-x: clip，hidden 会把 sticky/滚动容器一起弄坏
7 layout/100vw 100vw
100vw 在带滚动条的桌面会溢出，用 100% 或 dvw
8 a11y/html-lang <html> 没有 lang
补 lang="zh-CN" 之类
9 a11y/img-alt <img> 没有 alt
装饰图 alt=""，内容图写清楚内容
10 a11y/heading-skip 标题层级跳级
h1 → h2 → h3，不跳级
11 a11y/focus-visible 项目里没有 :focus-visible
给所有可交互元素加 focus-visible 环，且不做延迟
12 slop/purple-blue-gradient 紫→蓝渐变
换掉；强调靠权重、尺寸或一个真实色块
13 slop/eyebrow 标题上方的 eyebrow / 逐字间距小标签
删掉那行标签，让标题自己扛
14 render/overflow-x 渲染后出现横向溢出
找出溢出元素，改 minmax(0,1fr) / overflow-wrap / 缩小固定宽度
15 render/console-error 控制台报错
先修错误再谈视觉

REFLEX 有理由可豁免

12 条，是模型的默认反射，有真实理由可以保留。
#规则 id问题与改法
1 color/pure-extreme 纯黑或纯白
往主体色的色相里偏一点（oklch 里降一点 L 或加一点 C）
2 font/literal 字体族写死在规则里
字体也只走 token（--font-display / --font-body）
3 motion/bounce-easing 回弹缓动
用指数型 ease-out，别用过冲曲线
4 layout/viewport-height 100vh / h-screen
移动端地址栏会跳，首屏用 100svh 或 dvh
5 a11y/outline-none outline: none 没有替代焦点样式
用 focus-visible:ring / :focus-visible { outline: 2px } 代替
6 a11y/input-label 输入框没有可访问名称
加 <label for> 或 aria-label
7 slop/side-accent-border 卡片/提示条上的彩色侧边线
用背景色分层或留白，不要 1px 以上的侧边条
8 slop/hard-shadow 零模糊硬阴影
只有配方声明了硬阴影才用，否则用带偏移和模糊的柔和阴影
9 slop/nested-card 卡片套卡片
内层去掉边框/背景，用排版分层
10 slop/gradient-text 渐变文字
强调用字重或字号
11 type/tiny-text 小于 12px 的文字
正文最小 14px，说明文字最小 12px
12 type/measure 正文行宽超过 78ch
正文 measure 控制在 65–75ch

WARN 提示

4 条，只提示不阻塞。
#规则 id问题与改法
1 slop/emoji emoji 当图形用
换成真实图标或干脆不要图标
2 craft/important !important 过多
提高选择器特异性或用 @layer
3 craft/z-index z-index 用大整数
建立 0–50 的层级 token
4 render/no-puppeteer 渲染档不可用
npm i -g puppeteer-core 并提供 Chrome

八套配方

配方是材料，不是排版稿：它定纸、墨、强调色、字体、圆角、密度与动效曲线，不定区块顺序。发牌命令会给三个候选，选那个能扛住你素材的。

Broadsheet

broadsheet · editorial · normal

报纸、纸墨、严肃但不古板。签名：一条贯穿版面的细墨线，把标题和正文分开

Signal

signal · technical · compact

深色工程界面、等宽、一个电光色。签名：一个实时数据块，数字用等宽字直接摆在首屏

Linen

linen · soft · airy

棉麻、温和、留白大。签名：一张真实的材质照片，边缘用大圆角裁切

Atelier

atelier · luxury · airy

高级、克制、字号差距大。签名：一个巨大的产品名，下面一行极小的规格说明

Arcade

arcade · playful · normal

明快、有脾气、色块敢用。签名：一个能点的开关，按下去整块色域变色

Quarry

quarry · brutalist · compact

混凝土、硬边、极少量橙色。签名：一条 4px 的实心分隔线，把首屏切成两块

Harbor

harbor · product · compact

产品界面、冷静、密度高。签名：一个真实的表格，行高紧凑，数字右对齐等宽

Nocturne

nocturne · dark · airy

影院感、暗、暖色高光。签名：一张全幅暗调照片，标题压在照片暗部上

用法

作为 OpenCode / Claude Code / Codex 的 skill 安装，或者只把它当命令行 linter 用。

git clone https://github.com/aifeifei798/design-forge.git
cd design-forge
ln -sfn "$PWD/skill" ~/.agents/skills/design-forge

node skill/scripts/tokens.mjs deal --genre product
node skill/scripts/tokens.mjs emit harbor --tailwind --out src/forge-tokens.css
node skill/scripts/forge.mjs src/            # 静态检查
node skill/scripts/forge.mjs src/ --render   # 八宽度渲染（需 Chrome + puppeteer-core）

会话里说「做个落地页」会自动加载；也可以 /forge、/forge-audit、/forge-tokens 直接进对应流程。
